# Terminology

- **Status:** umbrella term for a battle-local boon or ailment. See [[Statuses]].
- **Boon:** positive status. See [[Boons]].
- **Ailment:** negative status. See [[Ailments]].
- **Definition:** authored reusable data, usually a Godot Resource.
- **Runtime state:** mutable battle-local state copied from definitions.
- **Scenario:** short handcrafted sequence of encounters. See [[Scenarios and Campaigns]].
- **Campaign:** availability, progression, and durable roster wrapper around scenarios.
- **Skill:** active job-granted action selected by tactics.
- **Passive:** deterministic combat hook with optional cooldown.
- **Reaction:** conditional response with optional cooldown.
- **Foretell:** deterministic speculative tactic evaluation. See [[Foretell]].
- **Guard armor:** temporary armor lasting until the unit's next turn.
- **Battle armor:** persistent armor modification for the current battle.
- **Scorched:** timeline-delay consequence from supporting a [[Burning]] unit; not a status.
- **Stun:** named timeline delay; not currently a status.
