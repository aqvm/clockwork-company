# Item Design Philosophy

Items should be build-warping artifacts: portable rules exceptions that make the player ask which unit, job, tactic order, party shape, or scenario matchup can exploit them.

Gear remains the primary between-scenario buildcraft lever, but it should not become a duplicate job system. Jobs define trained identity and reliable combat verbs. Items change the conditions under which those verbs become strange.

## Design Rules

- Normal reward items should usually have a bespoke hook, not only flat stat modifiers.
- Stat-only items are acceptable only when the modifier is extreme enough to become the identity of the item.
- Items should create questions, costs, constraints, or risks rather than simply answering a role need.
- Items should create emergent synergy with several jobs rather than naming or privately supporting one job.
- Items should bridge systems: statuses, armor, damage prevention, healing, tactics, action speed, death, positioning, enemy tags, scenario pressure, or party composition.
- Item effects should stay readable in tooltips and combat logs.
- New item behavior should prefer reusable resolver vocabulary, but a new resolver capability is worthwhile when it opens a durable item-design pattern.

## Boundary With Jobs

Jobs are authored careers. Items are portable complications.

- Jobs own reliable role identity, active decisions, baseline combat loops, and long-term progression identity.
- Items own conditional twists, risky accelerants, matchup tools, conversion engines, and temporary build pivots.
- Jobs should grant verbs such as healing, guarding, applying statuses, delaying, redirecting, or executing.
- Items should mostly bend what happens when those verbs are used.
- A job should function without a specific item. An item can become excellent with the right job, but it should not be required for the job to make sense.
- If removing an item makes the unit stop feeling like its job, the item is probably invading job design space.
- If equipping an item makes the unit's existing job do something surprising, the item is probably healthy.
